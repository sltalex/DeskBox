# DeskBox 2026101203

- 种树的五个阶段新增轻柔摇叶动画，分枝小树、茂盛中树和结果大树会飘落少量树叶。
- 移除树底部的阶段名称，保留成长进度和果实信息；进度条采用圆角绿色样式，百分比显示在轨道外。
- 系统监控支持分别选择 CPU、内存、网络图表的样式与颜色，新增黑色和白色选项，并可调整刷新频率。
- “外观 → 字体颜色”覆盖设置、搜索和功能格子，亮色主题默认灰黑色，暗色主题默认乳白色。
- 优化文件格子设置页的异步加载、种树能量刷新及桌面功能格子的层级行为。

本次提供 x64 直发安装包，保留原有安装标识和用户数据，可覆盖升级。主程序采用 Native AOT，温度采集辅助进程随包携带独立 .NET 运行时。暂不提供 ARM64 安装包。

动画遵循系统减少动画设置，格子隐藏后停止播放。

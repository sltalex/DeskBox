# DeskBox 1.5.6

This is the first x64 direct-install release published from [sltalex/DeskBox](https://github.com/sltalex/DeskBox). Direct builds now check `update/stable.json` in this repository and fall back to this repository's GitHub Releases. Microsoft Store builds continue to use Store updates.

The x64 installer is a Full Native AOT build. It retains the existing DeskBox AppId and is intended to upgrade an installed DeskBox in place. No ARM64 installer is included in this release; ARM64 clients will report that no compatible update is available.

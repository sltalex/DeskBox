# DeskBox 2026101001

## 中文说明

- “关于”页已移除“关于我”和“官方网站”按钮。
- 已移除问题反馈和“支持 DeskBox”入口。
- 新安装的直发版会在首次启动时默认启用开机自动启动；用户之后仍可在设置中关闭。
- 直发版继续从 `sltalex/DeskBox` 的 GitHub Release 获取更新。
- “种树”格子新增五种可爱的立体树形，从树苗逐步成长为结果大树。

## English

- Removed the About me and official website actions from the About page.
- Removed the feedback and Support DeskBox entries.
- Fresh direct installs enable launch at sign-in on first start; users can still disable it later in Settings.
- Direct builds continue to use GitHub Releases in `sltalex/DeskBox` for updates.
- The Tree widget now has five softly shaded growth illustrations, from seedling to fruit-bearing tree.
